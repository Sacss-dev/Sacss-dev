## Quantitative research
  * [Hawkes Processes](https://github.com/Sacss-dev/hawkes_processes) : Multivariate self-exciting point process MLE built from scratch on 0.9M NASDAQ level-3 events, modeling limit order book dynamics. Goodness-of-fit diagnostics drove a move from exponential to non-parametric power-law kernels, taking the branching ratio from 0.74 to 0.99 and recovering the near-critical regime documented for order flow. Out-of-sample R² of 0.130 on 1ms mid-price prediction vs 0.092 for a gradient-boosting baseline (+41% relative), under forward-chained train/test splits.
